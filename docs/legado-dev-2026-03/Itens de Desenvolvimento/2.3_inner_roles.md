# Plano de Ação: 2.3 Sistema de Sub-Tagueamento (Inner Roles)

## 🎯 Objetivo
Criar um mecanismo confiável e determinístico para extrair elementos internos de widgets complexos (como `image-box`, `icon-box`, `testimonial`, `button`), eliminando falhas de heurística onde o sistema confunde títulos com descrições. Isso se dará via injeção de metadados (`PluginData`) e nomenclatura de camadas.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. Modificação da Interface (UI):** Adicionar ações na aba do plugin para permitir que o usuário defina o papel específico de um nó selecionado. Ex: botões "Marcar como Título", "Marcar como Descrição", "Marcar como Ícone".
- [ ] **2. Injeção de Metadados (Figma API):** Criar uma função no `code.js` que se comunique com a UI e utilize `node.setPluginData('elementor_role', role)` para salvar a marcação no nó do Figma de forma invisível.
- [ ] **3. Suporte a Nomenclatura (Power-User):** Implementar leitura de `layer.name` para identificar sufixos como `[title]`, `[description]`, `[icon]`, como alternativa rápida ao uso dos botões.
- [ ] **4. Adaptação dos Handlers:** Modificar os parsers dos widgets complexos para primeiro buscarem a chave `getPluginData('elementor_role')` ou os sufixos no nome da camada nas camadas filhas. 
- [ ] **5. Fallback Heurístico:** Manter as regras baseadas em tamanho de fonte ou ordem posicional apenas caso o nó não possua nenhuma marcação explícita.

## ✅ Validações
- **Teste de Prioridade:** Criar no Figma um widget `image-box` onde a *descrição* tenha uma fonte maior que o *título*. Usar o sub-tagueamento para forçar a exportação correta. Ao colar no Elementor, o título deve estar no campo de Título, e a descrição no campo de Descrição.
- **Teste de Nomenclatura:** Renomear uma camada com `[icon]` e verificar se o JSON de fato extrai aquele elemento apenas como a chave de ícone, ignorando o restante.
- **Validação do Payload:** O JSON exportado precisa conter `title_text`, `description_text` (ou correlatos do widget) exatamente iguais aos nós sub-tagueados.
