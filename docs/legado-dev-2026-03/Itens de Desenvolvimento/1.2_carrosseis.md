# Plano de Ação: 1.2 Widgets Dinâmicos (`image-carousel` e `container-carousel`)

## 🎯 Objetivo
Desenvolver capacidade e suporte a arrays/laços de repetição na importação primária do DOM do Figma, viabilizando a transformação de containers-pai com filhos diretos para as estruturas iteráveis de dados referentes a galerias/carrosséis no Elementor.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. Função Utilitária de Iteração:** Criar suporte flexível em uma function utilitária no script `code.js` capaz de percorrer nós da árvore, iterando pelos "siblings" interligados (seleção múltipla) ou "children" de um Frame (seleção do nó pai).
- [ ] **2. Tratamento `image-carousel`:** Construir um bloco condicional (parser handle) responsável por mapear o widget de imagens no caso principal de tag iterada.
- [ ] **3. População de Array (`image-carousel`):** Fazer um filter iterativo para ignorar dados arbitrários e agrupar cada nó de imagem numa Array formatando os nós de maneira coerente e populando o objeto exigido: `{id, url}` dentro do atributo global `carousel` no JSON de configuração do widget.
- [ ] **4. Fallbacks Globais:** Assinar e popular padrões vitais de comportamento (estado default de atributos complexos do array), por exemplo: número de slides por página (`slides_to_show: 3`), navegação de arrows/dots (`navigation: "both"`) e restrição de dimensão (`image_size: "full"`).
- [ ] **5. Tratamento para `container-carousel` (Loops Recursivos):** Derivar a lógica para uma tag que envolva containers aninhados. O handler precisará iterar sob laços de agrupamentos e delegar renderings filhos (gerando as devidas referências únicas `id` e estrutura aninhada de elements em cada slide de container).

## ✅ Validações
- **Teste de Selecionamento Figma:** Executar seleção combinada (variando a captura: clicando em várias imagens isoladas simultaneamente OU no frame global englobador de imagens) com o botão de carousel dinâmico.
- **Validação do Payload da Array:** Interceptar e ler o DOM gerado virtualmente validando especificamente se a chave construtora do Widget contém a array populada em `carousel: [{url: "..."}]`.
- **Teste Prático Elementor:** Renderização frontal no motor principal importado. O widget ao ser importado precisa compor corretamente as setas/pontos do carousel, ser um carrossel estritamente dinâmico (com swipe por mouse/fricção) e honrar os fallbacks descritos na engine principal do script do Figma.
