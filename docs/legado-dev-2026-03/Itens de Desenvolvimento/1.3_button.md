# Plano de Ação: 1.3 Widget `button`

## 🎯 Objetivo
Desenvolver o tradutor e manipulador específico para o super-componente `button` garantindo que os fluxos completos do Elementor (estilizações, hiperlinks e grafismos de ícone compostos na UI) operem e reflitam o design do Figma sem atritos analíticos.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. Handler Principal Condicional:** Adicionar o nó da chave principal de entrada onde o sistema irá checar a equivalência para disparar o manipulador do elemento de CTA principal (`tag === "button"`).
- [ ] **2. Extração Central de Texto (`text`):** Isolar programaticamente o nó único ou primário englobando os metadados de texto (`characters`) daquele Frame selecionado do botão para mapeamento da chave `text` nas configurações centrais do JSON da chave do widget.
- [ ] **3. Propriedades Geométricas e UX (`align` e `size`):** Extrair a direção e alinhamento do Flexbox/Auto Layout interno do nó base, interpretando a orientação e determinando o `align` equivalente nativo do widget no Elementor (Ex: esquerdo, centro, esticar/justify). O padding interno balizará heurísticas estipulando chaves de volume referenciando as labels de `size` do WordPress (sm, md, lg).
- [ ] **4. Preenchimento de Propriedades de Estilo:** Escanear fills para captar cor do backplate de fundo (`background_color`) e cor de font base (`text_color`). Mapear cantos arredondados do frame exportado validando `cornerRadius` e formatando a tag global de `border-radius`.
- [ ] **5. Combinação Complexa de Vetores e Ícones (`icon`, `icon_align`, `icon_indent`):** Fazer a lógica analítica iterar pelos filhos do frame: se constatar um nó da API do Figma do tipo `VECTOR` irmão ao texto, acionar chaves de inserção no JSON contendo o SVG em string com o atributo `icon`. Checar a ordem na interface (esquerda ou direita do nó de texto) para preencher a flag de direção `icon_align` e espaçamento relativo `icon_indent`, usando os metadados de Gap do Auto Layout iterado.
- [ ] **6. Injeção Funcional e Hiperlinks (`link`):** Validar ligações e reactions do sistema nativo de Prototipação UI do Figma nesse nó do frame. Se a Action apontar para uma URL Externa (Link), derivar isso para a chave `link` do JSON gerador do Botão compondo os limites obrigatórios de link externo (`{ url: "https://xuxa.com", is_external: true/false }`).

## ✅ Validações
- **Teste Botão Seco:** Export via plugin com o frame simples possuindo apenas um background retangular de cor sólida e texto em seu interior.
- **Teste com Vetores/Ícones Mutantes:** Realizar bateria de testes permutando localizações do Ícone via Setas direcionais de Auto Layout no Figma (icon antes vs icon depois do texto) e avaliando a extração das chaves `icon_align` resultantes no script JS.
- **Teste Carga Dinâmica Prototype:** Definir interações ativas prototipadas ao frame de botão referenciando sites webs.
- **Teste Prático Elementor:** Ao se alimentar os dados JSON providos na UI web do construtor de páginas, avaliar a correlação semântica, validações de cliques web na exportação da label Link (no construtor e frontend publicado) e validação de tamanho total geométrico e espaçamento com ícone.
