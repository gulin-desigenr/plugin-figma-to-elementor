# Plano de Ação: 4.1 Ignorar Elementos Soltos (Não-Tagueados)

## 🎯 Objetivo
Melhorar a limpeza do payload JSON ignorando qualquer elemento ou frame no Figma que não tenha recebido uma tag específica. Isso evita que rascunhos, nós vagos ou caixas invisíveis poluam a extração e quebrem o layout principal.

## 📋 Checkpoints de Desenvolvimento
- [x] **1. Identificar o Nível de Verificação:** Localizado no `traverse.js`.
- [x] **2. Checagem de Tag:** Implementada trava `isInsideValidated` no `traverseNode`.
- [x] **3. Interrupção Segura:** Retornando `null` para nós sem tag fora de containers validados.
- [x] **4. Teste de Exclusão:** Validado pelo usuário que o plugin abre e a lógica de limpeza está ativa.

## ✅ Validações

- [x] Verificar o JSON para assegurar que apenas os containers com tag persistiram.
