# Planejamento original (branch `dev`, março de 2026)

Estes arquivos vieram da branch `origin/dev` (último commit em 28/03/2026), trazidos aqui em 2026-09-05 só como referência histórica.

O **código** dessa branch não foi trazido — era uma versão anterior do plugin, sem a extensão Chrome e sem os módulos de efeitos/seletores/validação que existem hoje em `src/`, superada pelo trabalho feito em `agent/figmentor-audit-baseline`. A branch `dev` continua existindo no GitHub caso algum dia seja preciso consultar o código daquela época, mas deixou de ser base de qualquer trabalho novo.

Os **documentos de planejamento** (`PLANO_DE_ACAO.md` e a pasta `Itens de Desenvolvimento/`) foram preservados porque descrevem a lógica original de cada feature (icon-box, carousels, botão, variáveis globais, exportação WebP, font-family, etc.) e podem ajudar a entender decisões de design que vieram depois.
