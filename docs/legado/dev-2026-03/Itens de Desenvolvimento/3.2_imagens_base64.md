# Plano de Ação: 3.2 Imagens e Assets em Base64 Data URI

## 🎯 Objetivo
Implementar a conversão nativa de bitmaps e imagens contidas no Figma para strings Base64 durante o processo de exportação. Isso possibilita que o usuário não necessite fazer upload manual de todas as imagens assim que importar a seção no WordPress, renderizando o asset de forma imediata.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. Validação de Fill Mídia:** No handler genérico ou específico (como em `mapImage`), detectar se o nó possui algum `fillStyle` do tipo `IMAGE`.
- [ ] **2. Extração de Bytes:** Utilizar a API apropriada `figma.getImageByHash(imageHash).getBytesAsync()` para obter o Uint8Array da imagem carregada dentro do nó.
- [ ] **3. Conversão Array Buffer para Base64:** Implementar uma função utilitária rápida no `code.js` (ou num módulo de core) que transforme o buffer de bytes da imagem resultante em uma string codificada em Base64.
- [ ] **4. Injeção Data URI:** Concatenar o mime type correto (ex: `data:image/png;base64,...` ou `jpeg`) com a string da imagem convertida e injetar na propriedade `url` da chave de imagem no JSON (`{ "url": "data:image/..." }`).
- [ ] **5. Estratégia de Otimização e Limites:** Planejar redimensionamento automático de imagens monstruosas pelo Figma em memória (caso necessário), visto que payloads JSON gigantescos podem esgotar memória no Clipboard ou dar erro na importação do Elementor.

## ✅ Validações
- **Renderização Imediata:** Colar o código de um `image` widget ou um `Container` (com plano de fundo contendo imagem). Ao colar no Elementor WP, a imagem deve carregar na tela instantaneamente, sem precisar abrir submenus de upload de mídia.
- **Verificação de Payload Limpo:** Consumir o JSON no console e validar se o prefixo `data:image/` está bem formatado e se não está quebrando a API formadora do parser.
- **Teste de Estresse (Opcional):** Tentar exportar uma seção com uma foto 4K no Figma e certificar-se de que o sistema não "crasha" com falha de memória ao tentar processar o array localmente.
