# Plano de Ação: 2.1 Modularização do Backend

## 🎯 Objetivo
Refatorar o monólito `code.js` separando lógicas de utilitários, tratamento de estilos e varredura de nós com o uso de um bundler (como `esbuild`). Além da modularização, este plano introduzirá a arquitetura de **Pseudo-Wrapper de Página**: O Frame pai (que engloba seções) será traduzido apenas como um agrupador virtual (pass-through), enquanto seus filhos diretos atuarão como as verdadeiras Seções da página no Elementor.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. Configuração do Bundler:** Instalar e configurar o `esbuild` no projeto `package.json`, criando um script de build (`npm run build`) capaz de compilar o código fonte em um único arquivo integrado (`dist/code.js`).
- [ ] **2. Separação de Utilitários (`utils/`):** Extrair funções auxiliares matemáticas e de interface como `figmaColorToRGBA`, `getIterableNodes` e `mapFontWeight` para arquivos modulares menores sob o diretório `utils/`.
- [ ] **3. Separação de Extratores (`styles/`):** Mover as funções de extrações de propriedades construtoras (ex: `extractBorders`, `extractShadows`, `extractBackground`).
- [ ] **4. Lógica Core e Handlers (`core/`):** Isolar a engine principal de varredura recursiva (`traverseNode`) e o cérebro das condicionais de widgets (`handleManualTag`).
- [ ] **5. Arquivo Raiz de Entrada (`index.js`):** Criar o arquivo centralizado que unifica os imports, escuta a API em `figma.ui.onmessage` e invoca a varredura primária.
- [ ] **6. Estrutura Pseudo-Wrapper (Página):**
  - Adicionar na UI (`ui.html`) um novo botão de tag: **"Página (Wrapper)"** (`tag === 'page-wrapper'`).
  - No código, ao ler a tag `page-wrapper`, a engine não gerará um container com estilos próprios, mas apenas iterará seus filhos (as verdadeiras seções), retornando uma array limpa (`return children`).
  - Adaptar a montagem final do JSON no `export-json` para achatar (`flat()`) o envio no array `content` do Elementor, permitindo a importação de múltiplas seções paralelas vindo de um mesmo Frame.
- [ ] **7. Atualização de Arquivos Root:** Atualizar o `manifest.json` para apontar `main` na saída do bundler (ex: `dist/code.js`).

## ✅ Validações
- [ ] **Validação de Build:** Rodar localmente o comando de compilação (`npm run build`) e garantir que nenhum erro de `import/export` ocorra.
- [ ] **Teste Prático da Engine (Figma):** Refazer a exportação integral de uma página complexa (botões, ícones, tipografias e containers aninhados). O plugin deve carregar normalmente.
- [ ] **Validação de Fidelidade (Elementor):** Importar este novo payload gerado pelo código desmembrado garantindo exatidão visual.
