# Plano de Ação: 3.3 Exportação de Imagens Tagueadas em WebP

## 🎯 Objetivo
Implementar um fluxo completo de exportação em lote de imagens presentes na seleção do Figma, convertendo-as para o formato **WebP** com qualidade configurável via slider, e disparando o download automático de cada arquivo para o computador do usuário — eliminando o processo manual de exportação e re-upload no WordPress.

---

## 📋 Checkpoints de Desenvolvimento

### FASE A — Interface (ui.html)

- [ ] **A1. Seção de Exportação de Imagens na UI:** Criar um bloco visual separado (abaixo da seção de exportação JSON), com título `"📥 Exportar Imagens"` e separador visual para distinguir das demais ações do plugin.

- [ ] **A2. Slider de Qualidade WebP:** Adicionar elemento `<input type="range" min="0" max="100" value="80" id="quality-slider">` com:
  - Label dinâmico ao vivo exibindo o valor atual (ex: `Qualidade: 80%`), atualizado via evento `input`.
  - Estilização customizada (CSS) consistente com o Design System do plugin: thumb arredondado, track com gradiente de roxo-profundo a branco, sem aparência nativa do browser.
  - Valor normalizado de `0–100` → `0–1` no momento do envio da mensagem ao `code.js`.

- [ ] **A3. Botão "Exportar Imagens":** Adicionar botão `id="btn-export-images"` com feedback de estado:
  - Estado normal: `"📥 Exportar Imagens"`
  - Estado carregando: `"⏳ Exportando..."` (botão desabilitado durante a operação)
  - Estado concluído: `"✅ Imagens Exportadas!"` (resetar após 3 segundos)

- [ ] **A4. Handler de Clique (UI → code.js):** Ao clicar no botão, enviar mensagem `{ type: "export-images", quality: <valor_slider / 100> }` via `parent.postMessage`.

- [ ] **A5. Handler de Recebimento de Dados (code.js → UI):** Ao receber mensagem `{ type: "images-exported", images: [{ name, bytes }] }`:
  - Iterar o array `images`.
  - Para cada item, criar um `Blob` com os bytes recebidos (`type: "image/webp"`).
  - Gerar URL temporária via `URL.createObjectURL(blob)`.
  - Criar elemento `<a>` programático com `download="nome-da-layer.webp"` e simular clique.
  - Revogar a URL após o download com `URL.revokeObjectURL`.

---

### FASE B — Backend (src/index.js)

- [ ] **B1. Handler `export-images` no index.js:** Adicionar bloco `if (msg.type === "export-images")` no `figma.ui.onmessage`.

- [ ] **B2. Função de Varredura de Nós Elegíveis:** Criar função auxiliar `collectImageNodes(node)` (recursiva) que retorna todos os nós elegíveis para exportação a partir de um nó raiz, seguindo os critérios:
  - Nó com plugin data `elementor-tag` igual a `"image"` ou `"image-carousel"`.
  - Nó com fill do tipo `"IMAGE"` (verificar `node.fills` com guard para `figma.mixed`).
  - Nó filho de `image-box` com plugin data `elementor_role` igual a `"image"`.
  - Nó do tipo `"RECTANGLE"` ou `"FRAME"` com fill de imagem detectado.

- [ ] **B3. Exportação com `exportAsync`:** Para cada nó retornado pela função de varredura:
  - Chamar `await node.exportAsync({ format: "WEBP", quality: msg.quality })`.
  - Sanitizar o nome da camada para uso como filename (remover caracteres especiais, tags `[...]`).
  - Acumular em array `[{ name: "<nome-sanitizado>.webp", bytes: <Uint8Array> }]`.

- [ ] **B4. Feedback de Progresso:** Emitir `figma.notify()` indicando quantas imagens foram encontradas e a qualidade aplicada (ex: `"⏳ Exportando 4 imagens em WebP (qualidade: 80%)..."`). Emitir segundo notify ao concluir: `"✅ 4 imagens WebP exportadas com sucesso!"`.

- [ ] **B5. Retorno para a UI:** Chamar `figma.ui.postMessage({ type: "images-exported", images: [...] })` com o array completo.

- [ ] **B6. Tratamento de Erros:** Envolver toda a operação em `try/catch`. Se nenhum nó elegível for encontrado, emitir `figma.notify("⚠️ Nenhuma imagem encontrada na seleção.", { error: true })` e não enviar mensagem de retorno, reabilitando o botão na UI.

## ✅ Validações

- **Teste 1 — Nó Simples com Tag `image`:** Taguear um único retângulo com imagem, clicar em "Exportar Imagens" e verificar se o arquivo `.webp` é baixado com o nome correto da camada.

- **Teste 2 — Qualidade Variável:** Exportar a mesma imagem com qualidade 10%, 80% e 100%. Comparar o tamanho dos arquivos resultantes no sistema de arquivos para confirmar que o slider impacta efetivamente o output.

- **Teste 3 — Múltiplas Imagens em Lote:** Selecionar um frame contendo 3+ imagens tagueadas. Confirmar que todos os arquivos são baixados sequencialmente sem travar a UI.

- **Teste 4 — Seleção sem Imagens:** Selecionar um frame que não contenha nenhum nó elegível e confirmar que o notify de aviso aparece e o botão retorna ao estado normal sem quebrar o plugin.

- **Teste 5 — Nome de Arquivo Sanitizado:** Taguear uma camada com nome contendo caracteres especiais (ex: `[IMAGE] Hero / Banner (Mobile)`) e verificar se o arquivo é baixado com nome limpo (ex: `hero-banner-mobile.webp`).

- **Teste 6 — Imagem dentro de `image-box`:** Verificar se o filho com `elementor_role = "image"` dentro de um nó `image-box` é corretamente detectado e exportado.
