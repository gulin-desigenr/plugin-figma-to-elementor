# Plano de Ação: 3.3 Exportação de Imagens em WebP

> **Referência técnica:** [WebP Generator Figma](https://github.com/tobias-schwerdtfeger/WebP-Generator-Figma) — análise do repositório de Tobias Schwerdtfeger.

---

## 🔍 Como o WebP Generator funciona (análise técnica)

A descoberta chave: **a API do Figma não suporta `WEBP` como formato** em `exportAsync`. Os formatos válidos são apenas `PNG | JPG | PDF | SVG | SVG_STRING | JSON_REST_V1`.

O WebP Generator resolve isso com uma arquitetura de dois estágios:

```
[Figma Backend]                    [UI / Browser]
────────────────                   ─────────────────────────────────
exportAsync(PNG, scale: Nx)  →→→   new Image() → <canvas>
                                   canvas.toDataURL('image/webp', quality)
                                   ↓
                                   JSZip → download único .zip
```

**Destaques da implementação:**
- `exportAsync` com `constraint: { type: 'SCALE', value: N }` para multi-resolução
- `Promise.all` paralelo para exportar todas as escalas simultaneamente
- Canvas API no browser converte PNG → WebP com qualidade configurável
- `JSZip` agrupa todos os arquivos num `.zip` com hierarquia de pastas
- Nenhuma dependência de servidor externo — 100% client-side

---

## 🎯 Objetivo

Implementar exportação WebP de imagens tagueadas no Figmentor, utilizando a **mesma arquitetura** do WebP Generator:
- Exportar como `PNG` no backend Figma
- Converter para `WebP` no browser via Canvas API
- Empacotar múltiplos arquivos num `.zip` único via `JSZip`
- Suportar escala configurável (1x, 2x, etc.) para Web e outros targets
- Download automático do `.zip` para o computador do usuário

  - Dropdown `<select id="export-scale">` com opções:

    - `2x (Retina)` → valor `2`

- [ ] **B4. Botão "Exportar Imagens":**
  - `id="btn-export-images"` com três estados:
    - Normal: `"📥 Exportar Imagens"`
    - Carregando: spinner animado + `"⏳ Exportando..."` (botão desabilitado)
    - Concluído: `"✅ X imagens exportadas!"` (reset automático em 3s)
  - Estilo `btn-secondary` com borda `accent-blue`, fundo levemente transparente

- [ ] **B5. Handler de Clique (UI → backend):**
  - Ao clicar, enviar:
    ```js
    parent.postMessage({ pluginMessage: {
      type: 'export-images',
      quality: sliderValue / 100,   // 0.0 – 1.0
      scale: parseInt(selectValue)  // 1 | 2 | 3
    }}, '*')
    ```

- [ ] **B6. Handler de Recebimento (backend → UI) — conversão e zip:**
  - Ao receber `{ type: 'images-exported', images: [{ name, bytes }], quality }`:
  1. Para cada imagem:
     - Criar `Blob` do `Uint8Array` com `type: 'image/png'`
     - Criar `URL.createObjectURL(blob)` e carregar em `new Image()`
     - No `img.onload`: desenhar em `<canvas>` com `naturalWidth × naturalHeight`
     - Chamar `canvas.toDataURL('image/webp', quality)` para obter string base64
     - Converter base64 para `Uint8Array` para adicionar ao JSZip
  2. Adicionar todos os arquivos `.webp` ao JSZip em pasta `webp-exports/`
  3. `zip.generateAsync({ type: 'uint8array' })` → criar Blob → download automático como `figmentor-webp-{timestamp}.zip`
  4. Resetar estado do botão
  - **Tratamento de erro:** se `canvas.toDataURL` retornar `'data:,'` (canvas vazio), pular o arquivo e logar aviso

- [ ] **B7. Handler de erro (backend → UI):**
  - Ao receber `{ type: 'images-export-error' }`: re-habilitar botão, limpar spinner

### FASE C — Backend (src/index.js)

- [ ] **C1. Handler `export-images` no `figma.ui.onmessage`:**
  ```js
  if (msg.type === 'export-images') {
    // lógica assíncrona aqui
  }
  ```

- [ ] **C2. Guard de seleção vazia:**
  - Se `figma.currentPage.selection.length === 0`:
    - `figma.notify('⚠️ Selecione um frame ou imagem primeiro.', { error: true })`
    - `figma.ui.postMessage({ type: 'images-export-error' })`

- [ ] **C3. Função `collectImageNodes(node)` — coleta recursiva:**
  - Percorrer a árvore a partir de cada nó selecionado
  - Critérios de elegibilidade (em ordem de prioridade):
    1. Nó com `elementor-tag` = `"image"` ou `"image-carousel"` ou `"image-background"` → elegível, parar recursão
    2. Nó do tipo `image-box` com filho de `elementor_role = "image"` → adicionar o filho, parar recursão neste ramo
    3. Qualquer nó (qualquer tipo) com fill `IMAGE` e que NÃO seja um container de layout (`container`, `container-full`, `page-wrapper`, `icon-box`, `icon-list`) → elegível, parar recursão
    4. Caso contrário, recursar nos `children` se existirem
  - Deduplicar por `node.id` após coleta
  - **Não** usar `figma.mixed` como fill sem guard

- [ ] **C4. Exportação com `exportAsync` em PNG + escala configurável:**
  ```js
  const bytes = await node.exportAsync({
    format: 'PNG',
    useAbsoluteBounds: true,
    constraint: { type: 'SCALE', value: msg.scale }
  });
  ```
  - Usar `useAbsoluteBounds: true` (mesmo comportamento do WebP Generator) para capturar o nó com sua área real sem clips

- [ ] **C5. Sanitização do nome do arquivo:**
  - Remover blocos `[...]` do nome da camada
  - Substituir caracteres especiais e espaços por `-`
  - Converter para lowercase
  - Limitar a 200 caracteres (evitar zips não descompactáveis)
  - Adicionar sufixo de escala: `nome-da-imagem@2x.webp` se `scale > 1`, `nome-da-imagem.webp` se `scale === 1`
  - Fallback: `image-{node.id}.webp` se nome resultar vazio

- [ ] **C6. Notify de progresso e conclusão:**
  - Antes de exportar: `figma.notify('⏳ Exportando N imagem(ns) em WebP (escala: Nx, qualidade: Q%)...')`
  - Após exportar: `figma.notify('✅ N imagem(ns) prontas para download!')`

- [ ] **C7. Envio para UI:**
  ```js
  figma.ui.postMessage({
    type: 'images-exported',
    images: [{ name: 'nome@2x.webp', bytes: Array.from(bytes) }],
    quality: msg.quality
  });
  ```

- [ ] **C8. Tratamento de erros com `try/catch`:**
  - Envolver toda a operação async
  - Em caso de erro: `figma.notify('⚠️ Erro: ' + err.message, { error: true })` + `postMessage({ type: 'images-export-error' })`

## ⚠️ Restrições e Decisões Técnicas

| Decisão | Motivo |
|---|---|
| Backend exporta `PNG`, não `WEBP` | A API Figma não suporta `WEBP` em `exportAsync` |
| Conversão PNG → WebP via Canvas API | Único método client-side sem servidor externo |
| `useAbsoluteBounds: true` | Captura o nó na sua área real (mesma abordagem do WebP Generator) |
| JSZip para empacotamento | Permite download de múltiplos arquivos em um único gesto |
| Sufixo `@2x`, `@3x` na escala > 1 | Convenção padrão Web/iOS para imagens retina |
