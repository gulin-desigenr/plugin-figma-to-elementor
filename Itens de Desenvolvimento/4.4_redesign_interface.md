# Plano de Ação: 4.4 Redesign da Interface (UI Overhaul)

## 🎯 Objetivo
Transformar completamente os artefatos visuais do `ui.html` para dar uma aparência premium e UX moderna ao Figmentor. Reduzir a velha listagem "crua" para um sistema limpo Figma-like, contendo Dark Mode, abas lógicas de uso e micro-interações fluidas.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. CSS Global e Variáveis:** Substituir a paleta padrão estabelecendo cores neutras (Slate/Zinc) e variáveis CSS globais no topo do `ui.html`. Estruturar os espaçamentos seguindo a base de design tokens.
- [ ] **2. Sistema de Abas (Tabs):** Criar views mutáveis em Vanilla JS que alterne entre painéis principais: "Exportador Automático" (Home), "Assets Avançado", "Suporte/Guia".
- [ ] **3. Componentes Ricos:** Estilizar os botões primários com animação glassmorphism ou hover iluminado, caixas suspensas fluidas, toggle switches com states elegantes, e tooltips úteis (ex: ícone i para explicar uma opção avançada).
- [ ] **4. Integração JavaScript / Messages:** Mapear IDs para garantir que o redesign do DOM não quebre nenhum dos antigos `document.getElementById('bto-x').addEventListener()` responsáveis por chamar o código Backend via IPC (parent.postMessage).
- [ ] **5. Feedback Visual de Processamento:** Adicionar Spinners/Loaders ou barras de progresso durante o parse, bloqueando o click duplo enquanto o JS do Figma itera num arquivo de 5 megabytes.

## ✅ Validações
- Compilar o ui.html. Selecionar o plugin no Figma e analisar visualmente.
- O Layout deve estar fluído, atraente, sem scroll indesejado e transicionando as abas suavemente na Sandbox UI.
