# Plano de Ação: 4.2 CSS Customizado Fantasma

## 🎯 Objetivo
Impedir que diretrizes CSS de posicionamento absoluto ou propriedades customizadas fiquem anexadas indevidamente ("fantasmas") aos settings do Elementor, quebrando layout e fluidez de edição dentro do WordPress.

## 📋 Checkpoints de Desenvolvimento
- [ ] **1. Rastrear Injeção Fantasma:** Pesquisar no `handlers.js` e `mapContainer` pelas propriedades injetadas que forçam position absolute, margin customizada, ou CSS inline.
- [ ] **2. Sanitização de Settings:** Expurgar propriedades corrompidas e remover keys geradas por acidente, tais como chaves que contêm `_position`, offsets indesejados e CSS fields sem mapeamento oficial.
- [ ] **3. Padronização de Defaults:** Garantir que o plugin unicamente preencha chaves de Flexbox oficiais (ex: `flex_direction`, `justify_content`, `align_items`).
- [ ] **4. Teste de Inspeção de Código:** Após exportar para o Elementor, inspecionar se a aba "Avançado > Custom CSS" e "Avançado > Layout" continuam intocadas ou dentro do comportamento natural.

## ✅ Validações
- Importar JSON no Elementor e demonstrar que a liberdade de edição do container/widget se mantém 100% nativa sem nenhuma regra CSS hardcore fixada.
